# 记账本

小樱的粉色磨砂记账本。纯静态网页，没有服务器。每一笔账都只存在你自己的浏览器里（`localStorage`）。

线上地址：<https://cherry95823.github.io/jizhang/>

## 怎么用

底下三个入口：

- **日历**：点某一天，月历收成那一周。先看当天的收入、支出和结余，再看每一笔。右下（日历中间上方）的「记一笔」用来新增。点记录可以改、可以删。
- **连续 / 多选**：在月历上选一段连续日期，或点开不连续的几天，再看「查看汇总」。里面有总数、分类、钱包，以及细线的环形图和每日柱图。
- **看板**：四只钱包各自的余额，和这个月的收入、支出。点进去看流水。生活费还会按分类收起支出，点开能看到里面的每一笔。
- **设置**：换背景、改起始余额、助学金起算日、分类、导出 / 导入 JSON、载入示例、清空。

四只钱包是固定的：生活费、奖学金、助学金、小金库。收入和支出都必须选一只。

助学金从「起算日」开始，每个月 10 日自动记一笔 ¥500 的收入。中间几个月没打开，下次打开会一次补上，不会重复。这笔和手记的账一样，可以改、可以删；删掉的那个月不会再自动补回来。

第一次打开会问每只钱包的起始余额，没有就填 0。

## 背景

打开就是「雨窗玫瑰」。设置里的「背景」可以换成「水中樱花」，或点「上传背景」从相册选一张。上传的图会缩小后存在这台设备里（IndexedDB），可以留好几张，点选使用，也可以删掉。

「纱罩浓淡」是照片上那层薄粉。往浓拉，字更清楚；往淡拉，照片更清楚。这个选择会记住。

自己上传的照片如果加起来超过大约 900KB，导出备份时不会带上，只会导出账本，并提示一声。内置的两张壁纸本来就在网页里，不用写进备份。

想换成别的内置图，可以把新图压成宽约 1080 像素，放到 `assets/bg/`，再在 `css/styles.css` 里给 `.bg[data-theme="rose"] .bg-photo` 换地址。樱花那张用 `background-position: center 42%`，竖屏裁切时花朵还留在画面中间。

## 备份

设置里的「导出备份」会下载一个 JSON 文件。换手机或清浏览器之前先导出，再到新设备上「导入备份」。清空数据、或清掉这个网站的浏览器数据，账本就没有了。

「载入示例数据」只为了预览界面，会换掉当前账本。平时打开是空的。

## 添加到主屏幕

用手机浏览器打开后，选「添加到主屏幕」。已经带了清单、图标和一个很薄的 service worker，装好之后没网也能再打开（字体第一次需要联网）。

## 本地预览

页面用了 ES Module，不要直接双击 `index.html`。在仓库目录里：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

逻辑测试（余额、助学金 10 日补记、按天和按区间的合计、壁纸偏好）：

```bash
npm test
```

## 发布到 GitHub Pages

`.github/workflows/pages.yml` 会在推送到 `main` 时，用 Actions 把仓库根目录部署出去。

还需要你自己做一次：打开仓库的 **Settings → Pages**，**Source** 选 **GitHub Actions**。只选这一次。选好之后，每次推到 `main` 都会更新 <https://cherry95823.github.io/jizhang/>。

如果 Pages 还没选成 GitHub Actions，工作流即使跑了也发不出去。
